# LaTeX report

Compile `main.tex` (Overleaf: upload this whole folder as a project and press Recompile;
locally: `tectonic main.tex` or `latexmk -pdf main.tex`). The output is `main.pdf`, to be
submitted as `Report.pdf`.

| File / folder | What it is | Edit it? |
|---|---|---|
| `main.tex` | Our title page + puts the document together; switch `\showdispositiontrue/false` here | Rarely |
| `preamble.tex` | Packages and settings | Rarely |
| `sections/*.tex` | One file per section: the text. Each has yellow *disposition* boxes; write the final text under `% Final text:` and delete the box when done | **Yes** |
| `references.bib` | Sources; cite with `\cite{key}` | Yes |
| `figures/`, `tables/` | Generated by `Report.ipynb` (re-run it to update) | No |

Cross-references update automatically: `Figure~\ref{fig:2.3}`, `Table~\ref{tab:7.1}`,
`Section~\ref{sec:4.8}`.

The matched-model continuation exports two additional tables using
`.venv/bin/python tools/build_paired_results.py` from the repository root:
`tables/tab_updated_models.tex` and `tables/tab_updated_hyperparameters.tex`.
These compare the previous 029/030 pair with the improved 039/040 pair. The existing
report text and historical tables are preserved; see
[the update guide](../docs/PAIRED_MODELS_2026-11-04.md) before replacing them.
